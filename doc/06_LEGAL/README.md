# Legal

Conteudo canonico desta pasta:

- `01_POLITICA_DE_PRIVACIDADE.md`: politica oficial de tratamento de dados do app.
- `02_TERMOS_DE_USO.md`: regras de uso da plataforma.
- `03_BASE_NORMATIVA_E_CHECKLIST_LOJAS.md`: base legal e checklist de publicacao em lojas.

Uso recomendado:

1. Atualizar estes documentos antes de qualquer build de release.
2. Manter links e contatos sincronizados com o backend (`/legal/*`).
3. Revisar com assessoria juridica antes de publicar em producao.
