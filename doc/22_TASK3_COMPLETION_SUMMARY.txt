- Refresh token: 7 dias (armazenado em BD)
- Token rotation automática

- Validação de DTOs

## 🎯 COMO USAR

### 1. Instalar & Configurar

```bash
cd backend
npm install
# Editar .env com JWT_SECRET e REFRESH_TOKEN_SECRET
npm run prisma:migrate
```

### 2. Iniciar Server

```bash
npm run start:dev
# Acessa em http://localhost:3001
# Swagger: http://localhost:3001/api/docs
```

### 3. Testar Signup

```bash
curl -X POST http://localhost:3001/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email":"user@test.com",
    "name":"Test User",
    "password":"SecurePass123!",
    "passwordConfirm":"SecurePass123!"
  }'
```

### 4. Testar Login

```bash
curl -X POST http://localhost:3001/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email":"user@test.com",
    "password":"SecurePass123!"
  }'
```

### 5. Usar Token

```bash
curl -X GET http://localhost:3001/api/me \
  -H "Authorization: Bearer {accessToken}"
```
