# Documentacao do Projeto Meu Agito

## Objetivo
Centralizar a documentacao oficial do projeto com ordem unica de leitura, separacao entre estado atual e historico, e trilha clara ate a finalizacao.

## Estrutura oficial
- `00_GOVERNANCA/`: regras da documentacao, estado atual validado, roadmap e matriz de validade.
- `01_PRODUTO/`: visao de produto e regras funcionais macro.
- `02_UX_FLUXOS/`: especificacoes detalhadas de telas, fluxos e componentes funcionais.
- `03_ARQUITETURA_E_ESTRATEGIA/`: arquitetura tecnica, stack e estrategias.
- `04_BACKEND/`: referencia de API e documentacao dos modulos backend.
- `05_REALTIME_SOCKET/`: guias de tempo real (Socket.IO).
- `06_LEGAL/`: politica de privacidade, termos de uso e checklist de lojas.
- `99_HISTORICO/`: snapshots antigos (nao canonicos para decisao atual).

## Ordem de leitura recomendada
1. `00_GOVERNANCA/00_GUIA_DOCUMENTACAO.md`
2. `00_GOVERNANCA/01_ESTADO_ATUAL_2026-04-23.md`
3. `00_GOVERNANCA/02_ROADMAP_ATE_FINALIZACAO.md`
4. `00_GOVERNANCA/03_MAPA_RENOMEACOES_2026-04-21.md`
5. `00_GOVERNANCA/04_MATRIZ_VALIDADE_DOCUMENTOS_2026-04-23.md`
6. `01_PRODUTO/`
7. `03_ARQUITETURA_E_ESTRATEGIA/`
8. `04_BACKEND/`
9. `05_REALTIME_SOCKET/`
10. `06_LEGAL/`
11. `02_UX_FLUXOS/`

## Regra principal
Somente documentos fora de `99_HISTORICO/` sao fonte de verdade para implementacao atual.
